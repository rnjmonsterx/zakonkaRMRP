ЮРИДИЧЕСКИЙ ПОМОЩНИК
====================

Полностью локальное настольное приложение для предоставленного корпуса документов.
Внешние источники законодательства не используются.

ЗАПУСК
------
START.bat

РАЗРАБОТКА
----------
py -3 main.py

АРХИТЕКТУРА
-----------
core/parser.py       Разбор и нормализация локальных Markdown-документов.
core/database.py     SQLite, FTS5, закладки, история, пересборка и диагностика.
core/references.py   Единый парсер перекрёстных ссылок.
core/settings.py     Сохранение и загрузка настроек.
ui/app.py            Основное окно и экраны приложения.
ui/widgets.py        Общие UI-виджеты.
ui/theme.py          Готовые палитры.

ДАННЫЕ
------
data/laws           Локальный корпус документов.
data/metadata.json   Метаданные корпуса.

legal_desk.db        Создаётся локально рядом с приложением.
settings.json        Создаётся локально рядом с приложением.

ОБНОВЛЕНИЕ БАЗЫ
---------------
База строится только из data/laws + data/metadata.json.
Перед пересборкой сохраняются закладки и история по стабильной паре:
имя файла + заголовок статьи.

ПРОВЕРКИ
--------
smoke_test.py        Быстрый интеграционный тест.

Windows EXE
-----------
build_exe.bat собирает one-file EXE через PyInstaller.
Ресурсы data/ и assets/ встраиваются в EXE, а БД и настройки остаются рядом с ним.
